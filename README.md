# Taste of Inner Mongolia

Four responsive pages introducing selected foods and food traditions in the Inner Mongolia Autonomous Region.

Live website: https://enzhuozhou.github.io/taste-inner-mongolia/
Repository: https://github.com/enzhuozhou/taste-inner-mongolia

## Pages and technology
- index.html: introduction and featured dishes
- foods.html: six selected foods, with Chinese names and context
- culture.html: cultural notes, source scope, and illustration credits
- explore.html: category filter with an announced result count

Semantic HTML, CSS Grid/Flexbox and plain JavaScript. All fonts, illustrations, styles and scripts work without third-party services. No database, authentication, or persistent data storage.

## Preview
Open index.html directly, or open the folder in VS Code and use Live Server. Use all navigation links and the category buttons. The mobile menu supports Escape. Navigation and food content remain accessible when JavaScript is disabled.

## Sources and authorship
The Culture page links to the source material. The ANU field-course article describes Mongolia and is used as comparative context, not direct evidence for all of Inner Mongolia. The Yale eHRAF link was removed from the site because its substantive summary could not be read during this review.

The supplied website and this revision use AI assistance for text, code and stylized vector illustrations. No photographs or third-party image files are included. The student must review the content, describe their contribution accurately, and be able to explain the code and design decisions.
